# notux-kernel
I'm using xv6fs from xv6 operating system for x86 and risc-v which I ported to 64, most of the filesystem code is for Russ Cox, Frans Kaashoek, Robert Morris, Eddie Kohler, this kernel was created for training purposes and not for use, just my attempt to make a 64-bit kernel that can run natively Linux applications and so on, without GPL licenses, and with a token root system
